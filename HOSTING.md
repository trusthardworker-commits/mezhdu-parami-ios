# Сайт «Между парами» на своём домене

Публикуйте содержимое `docs/` как обычный статический сайт. В папке находятся страница, стили, расписание, иконка и установочные файлы Scriptable для всех групп. Сборка и серверное приложение не нужны. Работает и в корне домена, и в подпапке (с завершающим слешем).

## Из закрытого репозитория через Cloudflare Pages

1. В Cloudflare Pages подключите GitHub и разрешите доступ к репозиторию `trusthardworker-commits/mezhdu-parami-ios`. Выберите ветку `main`.
2. Оставьте корень проекта и команду сборки пустыми. В качестве выходной папки укажите `docs`. Запустите публикацию и откройте выданный адрес.
3. Чтобы привязать домен, откройте **Custom domains → Set up a domain** в проекте Pages и следуйте подсказкам для DNS. После выпуска HTTPS-сертификата откройте свой адрес.

[Подключение GitHub](https://developers.cloudflare.com/pages/get-started/git-integration/) · [Настройка домена и DNS](https://developers.cloudflare.com/pages/configuration/custom-domains/)

## Через GitHub Pages

Если ваш тариф поддерживает Pages для этого репозитория, откройте **Settings → Pages**, выберите **Deploy from a branch → main → /docs → Save**. После публикации задайте **Custom domain**, настройте DNS по инструкции GitHub и включите HTTPS, когда он станет доступен. На GitHub Free Pages доступен для публичных репозиториев.

[Доступность GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [Настройка домена](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)

## После переезда

Откройте новый адрес, выберите группу и нажмите «Добавить виджет». И скачанный файл, и код для ручной установки запомнят адрес этой страницы, включая подпапку. На новом домене браузер попросит выбрать группу заново, если она не указана в ссылке.

Уже установленные виджеты продолжают показывать пары офлайн. Чтобы нажатие открывало новое расписание, переустановите скрипт с нового сайта или настройте перенаправление со старого адреса с сохранением параметра `?group=`.

Если вы раздаёте исходные файлы из `docs/widgets/` напрямую, их резервный адрес задаётся при сборке: `python tools/build_web_widgets.py https://ваш-домен/`. При установке через кнопку на сайте адрес определяется автоматически.

При обновлении исходных данных выполните `python tools/build_data.py`, `python tools/validate_data.py` и `python tools/build_web_widgets.py`. Загрузите обновлённые файлы в репозиторий. Для получения новых данных на iPhone повторно импортируйте скрипт своей группы.
