# Установка на iPhone с Windows, без Mac и Apple Developer

Этот способ использует бесплатную персональную подпись Apple. Она действует 7 дней, после чего её нужно обновить. Автообновление Sideloadly требует доступного компьютера и подключения телефона. Это ограничение подписи, а не расписания.

## Получить сборку

В GitHub-репозитории откройте **Actions → Build iPhone app**. После успешного завершения скачайте **Artifacts → FITeU-unsigned-iPhone**. Распакуйте скачанный ZIP — внутри должен быть `FITeU-unsigned.ipa`.

IPA пока не подписан. Просто открыть его на iPhone для установки нельзя.

## Подписать и установить

1. Скачайте [Sideloadly с официального сайта](https://sideloadly.io/) для вашей Windows. Следуйте его текущей инструкции по компонентам iTunes/iCloud; сайт указывает версии Apple для Windows. Не удаляйте уже установленные компоненты без необходимости.
2. Подключите iPhone кабелем, разблокируйте и подтвердите доверие компьютеру на телефоне.
3. Откройте Sideloadly, выберите телефон и перетащите в окно `FITeU-unsigned.ipa`.
4. Введите свой Apple ID в Sideloadly и запустите установку. Пароль и код подтверждения вводите самостоятельно, не в чат и не в GitHub. Платная подписка разработчика не требуется.
5. Если инструмент предлагает удалить расширения, **сохраните ScheduleWidget**. Без этого расширения приложение установится без виджета.
6. Если iOS просит, доверьтесь своему профилю разработчика в «Настройки → Основные → VPN и управление устройством». Для запуска локально подписанного приложения может потребоваться «Настройки → Конфиденциальность и безопасность → Режим разработчика» с перезагрузкой и подтверждением на устройстве.
7. Откройте приложение хотя бы один раз и выберите группу, например 23ПИжб.

## Поставить виджет

1. Удерживайте свободное место на экране «Домой» и откройте добавление виджетов.
2. Найдите «Между парами», выберите размер и добавьте.
3. Удерживайте новый виджет → **Изменить виджет → Группа → 23ПИжб**.

Выбор группы в приложении и в виджете независимый. Это позволяет обойтись без общего контейнера и настроить разные группы в нескольких виджетах. Все данные уже внутри, интернет для расписания не нужен.

Если виджет отсутствует в галерее: проверьте, что приложение уже открывалось, а при подписи сохранилось расширение ScheduleWidget. Если установка не проходит, нужен точный текст ошибки Sideloadly без пароля, Apple ID и кодов — до успешной установки нельзя считать работу на телефоне проверенной.

Источники: [Sideloadly и бесплатная подпись](https://sideloadly.io/), [ограничения бесплатной Personal Team Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/), [настройка настоящего виджета WidgetKit](https://developer.apple.com/documentation/widgetkit/making-a-configurable-widget).
