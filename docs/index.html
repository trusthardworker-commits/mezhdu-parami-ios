Виджет на iPhone

Пары твоей группы прямо на экране «Домой».

Виджет для

  1. Установи Scriptable из App Store.
  2. Скачай файл виджета. Открой его из «Загрузок» в приложении «Файлы», выбери Scriptable и нажми «Добавить» (Add to My Scripts).
  3. Удерживай свободное место на экране «Домой». В меню добавления виджетов найди Scriptable, выбери размер и добавь виджет.
  4. Удерживай виджет → «Изменить виджет». В поле Script выбери .
Если файл не открывается

Скопируй код. В Scriptable нажми «+», вставь код и задай скрипту имя, указанное выше. Затем выбери его в настройках виджета.

После 20:00 виджет показывает следующий день. iOS может обновить его с небольшой задержкой.
